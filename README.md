Реализованные задания
1. Задание 1:  
Два массива - первый сортируется по убыванию, второй по возрастанию, получается поэлементная сумма (совпадающие элементы дают 0), результат сортируется по возрастанию.

2. Задание 5:  
Подсчёт количества подмассивов, сумма которых равна заданному числу.

3. Задание 8:  
Подсчёт общих чисел между двумя массивами, включая числа, совпадающие со своей перевёрнутой версией (например, `123` и `321`).

- Ввод данных: вручную или случайно
- Алгоритм нельзя запустить без данных
- Результат нельзя вывести без выполнения
- При новых данных — результат сбрасывается
- Использован функциональный стиль (без классов)
- Каждое задание вынесено в отдельный модуль
- Восходящее проектирование: сначала функции, потом меню

Ветки
main — финальная версия программы (рекомендуется для проверки)
task1, task5, task8 — итерации по каждому заданию (демонстрация разработки)
